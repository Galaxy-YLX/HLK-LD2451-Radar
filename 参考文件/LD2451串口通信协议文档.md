## 1. 概述

本通信协议主要供需脱离可视化工具、进行二次开发的用户使用。LD2451 通过串口（TTL 电平）与外界通信，雷达的数据输出与参数配置命令均在本协议下进行。

**默认串口参数：**

| 参数 | 值 |
| --- | --- |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 奇偶校验 | 无 |

---

## 2. 协议格式

### 2.1 数据格式

- LD2451 的串口数据通信使用 **小端格式（Little-Endian）**。
- 本协议中所有数据均为 **十六进制**。

### 2.2 发送命令帧格式

| 帧头 | 帧内数据长度 | 帧内数据 | 帧尾 |
| --- | --- | --- | --- |
| `FD FC FB FA` | 2 字节 | 见表（命令字 + 命令值） | `04 03 02 01` |

**帧内数据格式（发送）：**

| 命令字（2 字节） | 命令值（N 字节） |
| --- | --- |

### 2.3 ACK 命令帧格式

| 帧头 | 帧内数据长度 | 帧内数据 | 帧尾 |
| --- | --- | --- | --- |
| `FD FC FB FA` | 2 字节 | 见表（返回值） | `04 03 02 01` |

**帧内数据格式（ACK）：**

| 发送命令字 & 0x0100（2 字节） | 返回值（N 字节） |
| --- | --- |

> 说明：ACK 帧内数据首 2 字节为原命令字的高位替换（原 `0x00XX` → `0x01XX`），随后为返回内容。

## 3. 命令配置流程

LD2451 执行一条配置命令包含「上位机发送命令」与「雷达回复 ACK」两个环节。若雷达无 ACK 回复或 ACK 失败，则说明命令执行失败。

**固定步骤：**

1. 先发送 **使能配置** 命令（其他命令必须在其之后下发生效）；
2. 在规定时间内发送所需配置/查询命令，并等待 ACK 成功；
3. 发送 **结束配置** 命令，雷达恢复工作模式。

> 如需再次下发其他命令，需重新发送「使能配置」命令。

```
上位机                  LD2451
  |--- 使能配置 -------->|
  |<-- ACK(成功) --------|
  |--- 配置/读取命令 --->|
  |<-- ACK(成功) --------|
  |--- 结束配置 -------->|
  |<-- ACK(成功) --------|
```

## 4. 命令列表

| 命令 | 命令字 | 命令值 | 返回值 |
| --- | --- | --- | --- |
| 使能配置 | `0x00FF` | `0x0001` | ACK 状态 + 协议版本 + 预留 |
| 结束配置 | `0x00FE` | 无 | ACK 状态 |
| 目标检测参数配置 | `0x0002` | 4 字节 | ACK 状态 |
| 读取目标检测参数 | `0x0012` | 无 | ACK 状态 + 4 字节参数 |
| 灵敏度参数配置 | `0x0003` | 4 字节 | ACK 状态 |
| 灵敏度参数查询 | `0x0013` | 无 | ACK 状态 + 4 字节参数 |
| 读取固件版本 | `0x00A0` | 无 | ACK 状态 + 版本信息 |
| 设置串口波特率 | `0x00A1` | 2 字节索引 | ACK 状态 |
| 恢复出厂设置 | `0x00A2` | 无 | ACK 状态 |
| 重启模块 | `0x00A3` | 无 | ACK 状态 |

> 所有返回值的「ACK 状态」均为 2 字节：`0x0000` 成功，`0x0001` 失败。

## 5. 命令详细说明

### 5.1 使能配置命令

其他任何命令必须在本命令下发后方可执行，否则无效。

- 命令字：`0x00FF`
- 命令值：`0x0001`
- 返回值：2 字节 ACK 状态（0 成功 / 1 失败）+ 2 字节协议版本（`0x0001`）+ 2 字节

**发送数据：**

```
FD FC FB FA  04 00  FF 00  01 00  04 03 02 01
             |长度|  |命令字| |命令值|
```

**雷达 ACK（成功）：**

```
FD FC FB FA  08 00  FF 01  00 00  01 00  00 00  04 03 02 01
             |长度|  |命令字| |状态| |版本| |预留|
```

---

### 5.2 结束配置命令

执行后雷达恢复工作模式；如需再次下发命令，需重新发送使能配置。

- 命令字：`0x00FE`
- 命令值：无
- 返回值：2 字节 ACK 状态

**发送数据：**

```
FD FC FB FA  02 00  FE 00  04 03 02 01
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  FE 01  00 00  04 03 02 01
```

---

### 5.3 目标检测参数配置命令

- 命令字：`0x0002`
- 命令值：4 字节

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 最远检测距离 | 1 字节 | `0A`~`FF`，单位：米 |
| 运动方向设置 | 1 字节 | `00`：只检测远离；`01`：只检测靠近；`02`：均检测 |
| 最小运动速度设置 | 1 字节 | `00`~`0x78`，单位：km/h |
| 无目标延迟时间设置 | 1 字节 | `00`~`FF`，单位：秒 |

- 返回值：2 字节 ACK 状态

**发送数据（示例：最远 100m / 只检测靠近 / 最小 5km/h / 延迟 2s）：**

```
FD FC FB FA  06 00  02 00  64 01 05 02  04 03 02 01
                      |命令字| |64 01 05 02|
                               最远100 靠近 最小5 延迟2
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  02 01  00 00  04 03 02 01
```

---

### 5.4 读取目标检测参数命令

- 命令字：`0x0012`
- 命令值：无
- 返回值：2 字节 ACK 状态 + 4 字节配置值（格式同 5.3）

**发送数据：**

```
FD FC FB FA  02 00  12 00  04 03 02 01
```

**雷达 ACK（示例）：**

```
FD FC FB FA  08 00  12 01  00 00  64 01 05 02  04 03 02 01
                             |状态| |64 01 05 02|
```

---

### 5.5 雷达灵敏度参数配置命令

- 命令字：`0x0003`
- 命令值：4 字节

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 累积有效触发次数 | 1 字节 | `01`~`0A`：连续检测次数满足才上报报警；程序默认 1 |
| 信噪比阈值等级 | 1 字节 | `00`：程序默认（4）；`03`~`08`：值越大灵敏度越差、越难检测 |
| 扩展参数 | 1 字节 | `00` |
| 扩展参数 | 1 字节 | `00` |

- 返回值：2 字节 ACK 状态

**发送数据（示例：触发次数 2，阈值等级 8）：**

```
FD FC FB FA  06 00  03 00  02 08 00 00  04 03 02 01
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  03 01  00 00  04 03 02 01
```

---

### 5.6 雷达灵敏度参数查询命令

- 命令字：`0x0013`
- 命令值：无
- 返回值：2 字节 ACK 状态 + 4 字节灵敏度值（格式同 5.5）

**发送数据：**

```
FD FC FB FA  02 00  13 00  04 03 02 01
```

**雷达 ACK（示例：触发 1 次，默认阈值 4）：**

```
FD FC FB FA  08 00  13 01  00 00  01 00 00 00  04 03 02 01
```

---

### 5.7 读取固件版本命令

- 命令字：`0x00A0`
- 命令值：无
- 返回值：2 字节 ACK 状态 + 2 字节固件类型（`0x2451`）+ 2 字节主版本号 + 4 字节次版本号

**发送数据：**

```
FD FC FB FA  02 00  A0 00  04 03 02 01
```

**雷达 ACK（成功，版本 V1.01.24051510）：**

```
FD FC FB FA  0B 00  A0 01  00 00  51 24  01 01  10 15 05 24  04 03 02 01
                             |类型   | |主版 | |次版本   |
```

---

### 5.8 设置串口波特率

配置值掉电不丢失，重启模块后生效。

- 命令字：`0x00A1`
- 命令值：2 字节波特率选择索引
- 返回值：2 字节 ACK 状态

**波特率选择表：**

| 索引 | 波特率 |
| --- | --- |
| `0x0001` | 9600 |
| `0x0002` | 19200 |
| `0x0003` | 38400 |
| `0x0004` | 57600 |
| `0x0005` | 115200（出厂默认） |
| `0x0006` | 230400 |
| `0x0007` | 256000 |
| `0x0008` | 460800 |

**发送数据（示例：索引 0x0007 → 256000）：**

```
FD FC FB FA  04 00  A1 00  07 00  04 03 02 01
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  A1 01  00 00  04 03 02 01
```

---

### 5.9 恢复出厂设置

将所有配置值恢复为出厂值，重启模块后生效。

- 命令字：`0x00A2`
- 命令值：无
- 返回值：2 字节 ACK 状态

**发送数据：**

```
FD FC FB FA  02 00  A2 00  04 03 02 01
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  A2 01  00 00  04 03 02 01
```

---

### 5.10 重启模块

模块收到命令后，在应答发送完成后自动重启。

- 命令字：`0x00A3`
- 命令值：无
- 返回值：2 字节 ACK 状态

**发送数据：**

```
FD FC FB FA  02 00  A3 00  04 03 02 01
```

**雷达 ACK（成功）：**

```
FD FC FB FA  04 00  A3 01  00 00  04 03 02 01
```

## 6. 雷达数据输出协议

LD2451 通过串口输出雷达探测结果。默认未检测到目标时仅输出帧头、帧长度、帧尾；检测到目标时会额外输出目标数量、角度、距离、速度等信息。

### 6.1 上报数据帧格式

| 帧头部 | 帧内数据长度 | 帧内数据 | 帧尾部 |
| --- | --- | --- | --- |
| `F4 F3 F2 F1` | 2 字节 | 见表 | `F8 F7 F6 F5` |

### 6.2 帧内数据格式

| 目标数量 | 报警信息 | 目标 1 信息 | 目标 2 信息 | … | 目标 N 信息 |
| --- | --- | --- | --- | --- | --- |
| 1 字节 | 1 字节 | 5 字节 | 5 字节 | | 5 字节 |

**单个目标信息（5 字节）：**

| 角度 | 距离 | 速度方向 | 速度值 | 信噪比 |
| --- | --- | --- | --- | --- |
| 1 字节 | 1 字节 | 1 字节 | 1 字节 | 1 字节 |

**字段说明：**

| 字段 | 说明 |
| --- | --- |
| 报警信息 | `0x01`：有目标靠近；`0x00`：无靠近目标 |
| 角度 | 单位：度；实际角度值 = 上报值 − `0x80`（范围约 −128~+127 度） |
| 距离 | 单位：米；范围 0~100 |
| 速度方向 | `0x01`：靠近雷达；`0x00`：远离雷达 |
| 速度值 | 单位：km/h；范围 0~120（结合方向为带符号速度） |
| 信噪比 | 0~255 |

## 7. 数据上报解析实例

**原始数据：**

```
F4 F3 F2 F1  11 00  03 01  8A 28 00 3C 15  8A 1E 01 3C 0F  76 5F 00 3C 0F  F8 F7 F6 F5
             |长度|  |数量 报警| |  目标1    |  |  目标2    |  |  目标3    |
```

> 注：原协议 PDF 中目标 2 距离字节误印为 `IE`，实际应为 `1E`（30 米），此处已修正。

**解析：**

- 数据长度：`0x11` = 17 字节
- 报警信息：`0x01` → 存在靠近目标
- 目标数量：`0x03`

**目标 1：**

| 角度 | 距离 | 速度 | 信噪比 |
| --- | --- | --- | --- |
| `0x8A` → 10° | `0x28` → 40 m | `0x003C` → 靠近，60 km/h | `0x15` |

**目标 2：**

| 角度 | 距离 | 速度 | 信噪比 |
| --- | --- | --- | --- |
| `0x8A` → 10° | `0x1E` → 30 m | `0x013C` → 远离，60 km/h | `0x0F` |

**目标 3：**

| 角度 | 距离 | 速度 | 信噪比 |
| --- | --- | --- | --- |
| `0x76` → −10° | `0x5F` → 95 m | `0x003C` → 靠近，60 km/h | `0x0F` |
